# Sony Ericsson P908 与 Nokia 9210C

本批仅收录P908中号一款及9210C三款原生点阵固定字样。图中第一行用实际简体／繁体Unicode码位，第二行用同一字库层的原生ASCII，不借字、不把小字号放大成新款。字面尺寸与行字格分别记录，网站按原生行字格高筛选。

## 已核层与尺寸

| 条目 | GDR层UID | 典型汉字墨迹 | 原生行高／ascent | 常用汉字字进 | 映射码位／非空CJK |
|---|---|---|---|---|---|
| P908中号 | 0x18be | 13×14 | 16／13 | 14，另有一个汉字为13 | 16,635／15,788 |
| 9210C小号 | 0x100054f9 | 15×15 | 16／14 | 16 | 22,327／20,902 |
| 9210C中号 | 0x10005504 | 17×17 | 18／16 | 18 | 22,327／20,902 |
| 9210C大号 | 0x10005505 | 19×19 | 20／18 | 20 | 22,327／20,902 |

典型墨迹不是全库最大值。GDR层最大宽度分别为17、16、18、21px；西文按每字advance与bearing排版。CJK统计范围为U+3400–U+9FFF；9210C的20,902字具体为U+4E00–U+9FA5。四层均包含全部6,763个GB2312汉字和Python严格Big5编解码器所映射的13,061个汉字，逐字非空；不外推为完整Unicode、GBK或GB18030覆盖。各层95个可打印ASCII均有记录，只有空格无墨迹且保留原字进。

## 来源和校验

来源是[Twister历史手机固件存档资料页](https://archive.org/details/Twister_Mobile_Phone_Flashing_Box)中的Firmware.zip，不是本次实机读取。具体SHA及PPM变体记录见[data/phone-gdr-sources.json](../data/phone-gdr-sources.json)。不运行刷机软件或安装程序。

- P908：Firmware/Sony_Ericsson/P908/p908_r1a08_162023.zip，内部PD1的固件字符串为CXC162023 R1A08 031120 17:33，即2003-11-20。PD1前四字节为闪存地址，ROM目录给出Linnea.gdr，物理偏移0x188c554、长度1,821,475字节。GDR SHA256为debad6cef3b0b423fc53b32a923c87d0373671f929f520063d40117d6972cc4f。
- 9210C：Firmware/DCT-3 fireware/9210C RAE-3/rae3-36[1].13.exe，内部版本36.13，日期07-03-02与配置记录07.03.02一致，按2002-03-07解释。中国、台湾、香港三个PPM均通过ZIP CRC与各654个传输块的头部／载荷校验，内含逐字节相同的Linda.gdr，长度2,915,114字节，SHA256为4cee557f8edb16c096e708d13cc24ecd7ae7461f25b27ae46e57c925aa5a69f4。
- 该9210C存档的SFX中央目录偏移不一致，MCU成员DEFLATE流损坏。本次只使用独立通过校验的PPM，既未修复也未依赖MCU，不据此称整个安装包完好。

Linnea／Linda只是资源文件名，不是设计师或设计来源的证明。原生位图存储不自动证明逐点手绘历史。

## 解码与去重范围

两份GDR均为Unicode区段索引、8字节内联字符指标、LSB先行的单色行压缩位图。指标保留ascent、墨迹高、左bearing、advance及右bearing。P908版本40；9210C虽为版本39，但结构不同于后期某些版本39文件，不能仅按版本号套用通用解码器。

- P908与具名完整GB汉字基线中，SimSun18030 v2.06内嵌14层为100/6763（1.479%）同形。它与T610中号6755/6763（99.882%）、P802中号6373/6763（94.233%）同形，故只保留覆盖更全的P908代表，不将另两机型计作独立设计。Nokia3350的14高标题子集为40/44同形，该小子集不能外推全库。
- P908同文件的另外两款中文层与SimSun对应层超过99%同形，本批排除。
- 9210C逐同码位比较47个具名字库层，其中45层包含全部6763个GB汉字。15点典型墨迹层最高6/6763（0.08872%）；17／19点层在这些基线实际覆盖的GB、Big5及共同CJK码位中均无同形。
- 另对c35ae基底main的234条目逐一审计：233张原生固定PNG，1张参考图不作字库比较。P908只在Sun GBK14样文中命中一个“广”（1/10），9210C三层无样字同形。四个独立正对照均通过10/10。已移除来源中23份可用BDF的5–14个样字也无同形；1份映射不可用、11份来源缺失，明确未完成其比较。

发布基底随后更新为含AIX的75096b0，共235个既有条目。另补查AIX新增固定繁体样文，四个手机层各10个同码汉字均无精确图案命中；原234项审计基底未改写。

比对只裁外缘空白、不缩放。详见[具名字符层结果](../data/phone-gdr-dedup.json)、[当前与已移除固定样字审计](../data/phone-gdr-sample-audit.json)及[覆盖报告](../data/phone-gdr-coverage.json)。固定样字检查不是全库去重，本批不宣称穷尽全部当前、已移除或历史字体。

## 离线重绘

自行取得并确认有权处理匹配SHA的本地输入，安装Pillow后运行：

```sh
python scripts/phone_gdr_specimens.py local-research/Linnea.gdr --device p908 --output local-research/generated/p908
python scripts/phone_gdr_specimens.py local-research/Linda.gdr --device 9210c --output local-research/generated/9210c
```

P908也可传PD1并加`--container pd1`；9210C可传上述SFX并加`--container sfx`，或指定中国版RAE33036.0US并加`--container ppm`。脚本先核完整输入SHA，静态取出已核GDR，再验证区段、记录、压缩流边界、行数与覆盖。输出目录必须不存在；仅写四款对应固定两行PNG和聚合覆盖报告，不落盘完整GDR、字库子集或BDF，不自动联网获取输入。

样图保留原生字进、bearing、ascent及完整行格，画布外边4px、行间4px只是本展示的布局。未作设备实机UI复刻验证。
