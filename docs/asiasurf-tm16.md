本条展示 AsiaSurf 简版中 DLM_TM.WKF 的原16×16繁体位图层，固定文字为「視野無限廣窗外有藍天」。仅提供固定预览、可核验事实和离线重绘工具，不提供完整字体、原程序、原码全表或任意文字导出。

[CCIC 保存的 Windows 中文系统介绍](https://www.ibiblio.org/ccic/software/cnapps/mswcsys.html)是可浏览来源页。原包 README 自署 DynaLab Inc.、6/5/1996，并将简版描述为仅含 bitmap。1996 是版本载体时间，不是已证实的字体设计年；原说明中的完整字符集宣传不代替下面的实测覆盖。

原 DLFMP.DLL 的静态选层链将 DLM_TM.WKF 配为 DFM-MING-BIG5。目录沿既有“宋体 / 明朝”分类，依据该原始 MING 名称，不另凭外观命名风格，也不据产品署名推定每个字形的设计作者。

## 汉字覆盖与半角边界

- 基本Big5统一汉字13,061个全部非空，另2个兼容汉字。保留十／卅各自两个原码，共13,065个严格Big5汉字原码、13,063个不同Unicode标签；不是将两别名去掉后冒称原槽少两个。
- Big5第一主区5,401、第二主区7,652，加符号区12个汉字原码。第二主区含2兼容汉字，符号区含十／卅别名，分母不能混用。
- 另有7个CP950扩展汉字、34个扩展符号，全部非空，分别列示，不并入基本Big5分母。
- 13,973个DBCS物理槽中13,865非空、108空；116个非空槽没有所用现代CP950标签，保留原码，不从相似字形反赋Unicode。现代Unicode是本次语义标签，不是WKF内置映射。
- 原层还包含256个半角物理存储槽，但已核0x6f86入口先检查DBCS范围，单字节输入在该路径不可达。其他原路径及整系统ASCII覆盖未核，因此本条不展示或评估ASCII，不说“原库无ASCII”，不把95个可打印ASCII登记为源缺字。目录 asciiOrigin 为 unknown、asciiText 为空；asciiMissing 和 renderOmitted 为空不表示ASCII全覆盖。固定十汉字样文本身无缺字。

CM16及TM12因已知强重复不新增；本条只收TM16，不拆其他层。原转码表不用于补齐字模或给未知槽反向赋码。

## 已核比较及其限制

303条限定同码证据记录中，完整墨迹exact并集为18个不同Han，未发现整层高重复。逐原码跨303最佳值中，13,065基本原码有2,155个≥0.90、467个≥0.95；这是跨多个参考混合取最佳，不是一套参考字体的整体相似度。

另在60个限定原槽池比较，基本13,065原码的并集为：1,285个≥0.90、255个≥0.95、裁外空白后完整墨迹exact为12个、完整16框exact为9个。该口径不等于303同码比较；7个CP950扩展另列，仅「碁」达到0.90，未达0.95或exact。

相似度为完整前景的九种±1平移Dice，只裁外部全空白，不缩放、不裁内部、不挑相同局部。这些统计不能证明原创、每字手绘、传播方向或权利许可。303是证据记录数，60是限定原槽池数；均包含有限预览、图表、UI子集或声明范围，不等于303／60套完整独立字体，更不等于全历史中文字库。仍有12项完整原源未恢复缺口，ChinaSea参考资料图不能当完整字库比较。

## 离线重绘与检查

需要 Python 3.9+、Pillow，以及支持POSIX目录描述符和不跟随符号链接的系统。工具不联网、不安装或运行旧软件，不接受任意文本、字体替换、其他倍率或全字导出。输入文件须为单链接普通文件，路径各层不得为符号链接；输出父目录须已存在，输出PNG必须是新文件。工具拒绝覆盖源、已有目标、硬链接、FIFO及包含父目录跳转的路径。

例如，自行准备好本地源文件及输出目录后：

```sh
python3 scripts/asiasurf_tm16_specimen.py --source local-research/asiasurf/DLM_TM.WKF --output local-research/asiasurf/fixed-1x.png
python3 scripts/asiasurf_tm16_specimen.py --source local-research/asiasurf/DLM_TM.WKF --output local-research/asiasurf/fixed-4x.png --scale 4
python3 tests/asiasurf_tm16.test.py
ASIASURF_TM16_SOURCE=local-research/asiasurf/DLM_TM.WKF python3 tests/asiasurf_tm16.test.py
```

无源检查只验证公开固定文件和失败关闭行为，原源测试明确跳过；提供源后才进行独立网格定位、逐RGBA像素核对及源篡改／IO负控。未存在正式catalog时，集成专项也明确跳过，不能以此替代全站检查。编码器若不能产出锁定PNG字节则停止，不偷偷改图或改SHA。本工具仅重取十字，不重跑全部覆盖及相似度研究。
