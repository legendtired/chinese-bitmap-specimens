# v16 收录与展示边界

本次在原有 155 项基础上新增 36 项，目录合计 191 项：180 项原生或来源限定字样，11 项参考资料图。条目数不是独立字库或设计家族数。既有条目的稳定 ID、优先级、收藏和比较入口保留。

## 新增的 25 项原生字样

- Windows 韩文字体的中文位图：12px 选一个代表，14px 与 16px 各保留 Dotum / Batang，共 5 项。12px 两种设计很接近，但不是逐字完全一致；详情保留差异范围。
- MS Gothic / MS Mincho：10px 共享字形选一个代表，13px 与 16px 各两项，共 5 项。
- Osaka：9、14、18、24ppem 共 4 项；实际保存字框分别为 9×11、14×15、18×18、24×22，筛选按字框高而不是 ppem。
- Palm CJKOS：简体／繁体各 10px、12px，共 4 项；当前输入是中文字库，不以另一字体补 ASCII。
- ELISA：8×8 设计置于 10×8 BDF 字框，英数样行来自原字库全角字符，不宣称普通 ASCII 完整。
- FlipperCN：展示来源实际覆盖的菜单词，使用 10×11 排布字框；主体设计约 9px，不称全库 9×9。
- 炎黄 YH：同一条目展示简体、繁体及原配 ASCII，保持原位图，不据存储格式推定全部制作史。
- MaruMonica 中文扩展、Naga10、Paw16：分别采用原生 12×16、10×10、16×16 字框；不借用其他字库补字。MaruMonica 原 8220 字形与扩展部分适用不同许可，不能统一标成 OFL。
- CNS 40：直接读取 40×40 位图；英数使用原输入中的全角字形，制作历史仍有待核内容。
