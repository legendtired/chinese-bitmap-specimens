## 固定样图重绘

每字 32 字节。上 8 行、下 8 行各一页；每页 16 列，每列字节的最高位在最上方。脚本使用同包的 Unicode 映射核对固定样文的原码。样图逐像素保留 16×16 字框，16px 字进与行间距只是预览排版，未验证实机字进及基线。

自行取得有权处理的本地固件并校验 SHA-256。装有 Pillow 时可离线重绘（输出路径须为新的 PNG 文件）：

```sh
python3 scripts/wonder_ent702ve_specimen.py 本地固件.bin 固定字样.png
```

只展示固定短样图，不附完整字体、字模表或固件。厂家提供下载不代表字体可开放再分发。
