# 文曲星 NC1020 12×12：获取与提取

## 获取

1. 打开 [jswqx 的 rom 目录](https://github.com/hackwaly/jswqx/tree/master/rom)，在 `obj_lu.bin` 文件页点击 Download raw file。
2. 将 [wqx_to_bdf.py](../scripts/wqx_to_bdf.py) 保存到同一文件夹。
3. 安装 Python 3，运行：

```sh
python3 wqx_to_bdf.py obj_lu.bin nc1020-12.bdf
```

Windows 可将 `python3` 改为 `py`。输出含7,445个 Unicode 字符，其中6,763个汉字，用支持 BDF 的软件打开。脚本无第三方依赖，检查镜像校验值，并保留已有输出文件。

## 文件资料

来源为旧 NC1020 模拟器镜像，尚未与真机比对，字模许可待核实。

- 大小：25,165,824字节。
- SHA256：`d3bdc7847f3de1f7b58f12a07e51b3ca7f6d136d5f00ba626e39c591ea246c97`。
- 字模：12×12，每字18字节，MSB优先。
- 逻辑基址：`0x50C800`；文件地址为逻辑地址 XOR `0x4000`。
- 编码：GB2312；本次提取不含普通 ASCII。全角空格为空白，未发现全黑字符。
- 样句已按原始像素核对；6,763个汉字与所查 HZK12 输入无完全相同字形。
