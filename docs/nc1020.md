# 文曲星 NC1020 12×12：获取与提取

此条目已按用户选择列为推荐。推荐代表字样欣赏与研究价值，不代表商用许可或原厂真实性认证。

## 来源和边界

来源为 [jswqx 的 rom 目录](https://github.com/hackwaly/jswqx/tree/master/rom) 中 obj_lu.bin，是旧 NC1020 模拟器镜像，不是已确认的真机转储。原始字形作者、设计年代与字模再分发许可尚未核实，不能将模拟器的代码许可套用到 ROM 或字体上。

本站只公开固定样图和无字模的转换脚本，不提供完整 ROM、BDF 或字模数组。请先确认自己有权取得和使用输入；转换本身不产生商用或再分发授权。

## 本地操作

1. 自行取得与下列校验值一致的 obj_lu.bin。
2. 保存 [wqx_to_bdf.py](../scripts/wqx_to_bdf.py) 到同一文件夹。脚本只有 Python 3 标准库依赖，不联网、不安装字体。
3. 在终端运行：

```sh
python3 wqx_to_bdf.py obj_lu.bin nc1020-12.bdf
```

输出是 Unicode 映射的 BDF 位图字体，不是可直接双击安装的 TTF。使用支持 BDF 的工具，或仓库 scripts/render_bdf.py 查看实际像素。脚本拒绝未知镜像和覆盖已有文件，不要绕过校验套用其他 ROM。

- 镜像大小：25,165,824 字节。
- SHA256：d3bdc7847f3de1f7b58f12a07e51b3ca7f6d136d5f00ba626e39c591ea246c97。
- 12×12，每字18字节，MSB优先；逻辑基址0x50C800；文件地址等于逻辑地址 XOR 0x4000。
- 按 GB2312 严格解码并往返验证，共7445个独立Unicode字符，包含6763个汉字。只有全角空格为空白，未发现全黑字符。
- 已验证固定样句与原始像素一致；没有逐字人工校对全部字形，也没有实机比对。
- 本次提取范围没有普通ASCII，不表示设备没有其他西文字库。

汉字全集与所查 HZK12 输入不相同；仅凭样句不能断言与所有历史字库均无共同来源。
