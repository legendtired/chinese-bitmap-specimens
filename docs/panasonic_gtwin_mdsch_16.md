# Panasonic GTWIN / MDSCh PGothic · 16×16

来源：[Panasonic GTWIN 官方软件页面](https://industry.panasonic.eu/products/automation-devices-solutions/human-machine-interfaces/hmi-programming-software/programming-software-gt-series-gtwin)。GTWIN V3.48 公开原厂软件包内的 mdschgp.ttf，内部名 MDSCh PGothic，版本1.03，版权标注2001 Ricoh／CITS；不是具体设备年份或物理ROM实测。

## 字模

原存 EBDT/EBLC 16ppem 1-bit bitmap format 5，16×16 汉字与8×16 ASCII，原字进和13像素垂直 bearing。Unicode cmap 对应7,538个映射，其中全部6,763个GB2312汉字及95个可打印ASCII。16点汉字与同一软件中的 parts_font_chs.dat 全部6,763个裁外白同形。没有将矢量轮廓取模。

## 去重

对照当时私库263份BDF中的262份（HPUX Sung42传输失败），16点最大精确重合率为 Apple 黑体16 的124/6763（1.83%）。12点与 Olympus m:robe 12点有3307/6763个重合，依选择暂不收录。
