# HP-UX 繁体宋体 24／34／42 点

本批展示 HP Sung 原生 PCF 的三个尺寸，配同源半宽西文。不执行安装盘程序，不从轮廓字体取模，不补画、缩放或合并编码变体。

## 来源与年份

[HP-UX 11i Version 1，2005年9月原盘存档](https://archive.org/details/hp-ux-11i-version-1-mission-critical-operating-environment-sept-2005)，第2盘 B7994-10045。字体内部标记 Copyright (c) 1994 Hewlett-Packard Company。1994是字体版权标记；2005是本次介质日期，均不证明最初设计过程或手绘历史。

原文件位于 Asian-X11 下的 XFNT-TCH-E-MIN、XFNT-TCH-E-AUX、XPFT-TCH-E-AUX 文件集中，usr/lib/X11/fonts/hp_chinese_t/75dpi 路径。各尺寸使用 sung24/34/42n1.pcf、n2.pcf、na.pcf。光盘文件实际为 gzip 包装，先解压，PCF校验及ISO存储位置见 [源清单](../data/hpux-sung-sources.json)。清单是元数据，不含字模。

## 编码与原始度量

- n1/n2：CNS11643.1992 平面1／2；中文原字框24、34、42点。
- na：ISO646.1991-IRV，原宽分别12、17、21点，95个可打印ASCII保留原空格。
- 原ascent/descent分别22/2、32/2、36/6；固定样文保持相同基线和字进，四周4px、行间4px，不额外插字间距。
- glibc EUC-TW转换下，三尺寸各13,064个非空U+3400–9FFF汉字。与Python Big5的13,061字逐Unicode对照，覆盖13,060；Big5“彝”在该CNS映射对应“彞”，另外有亠、冫、勹。这里不借字补齐，也不声称完整Big5同Unicode覆盖。原码位可用于检查映射差异。

[覆盖统计](../data/hpux-sung-coverage.json)仅指本次两平面，不代表全部HP-UX语言支持。固定句的零缺字也不等于整个字符集零缺字。

CNS2尾部0x7245是原PCF默认fallback，现代EUC-TW转换却会映成“㎞”，与CNS1真实符号同Unicode异图。因此不能直接合并所有槽为Unicode完整字体；固定样文不使用该槽。本次未用第二独立CNS映射表验证，保留原码位和字集声明。

## 离线重绘固定样文

自行取得并确认有权使用上述九个解压PCF；安装 Pillow，系统须提供支持EUC-TW的iconv。运行：

```sh
python3 scripts/render_hpux_sung.py /本地/九个PCF所在目录 /本地/尚不存在的输出目录
```

工具核对每个输入的精确SHA256后只输出三张固定样文PNG，不联网、不安装字体、不输出完整BDF、不内嵌字模。输入不符或输出已存在会拒绝；不以其他字体补缺字。

## 去重范围

[聚合报告](../data/hpux-sung-dedup.json)：221份历史主BDF中211份有可映射非空汉字，另补DEC CNS24／32，共213个参考ID。24点最高ETen Taipei24／eb5_24f为16／13,060裁白相同（整框15）；34点零；42点最高CNS40为72／5,414裁白相同（1.33%），整框零。没有发现高比例精确复用，不等同证明原创。

当前230条基线中185个ID在旧包，45个缺完整源；即使在包内，也有三个当前项未能恢复可靠汉字映射。缺口、撤下项及ENCODING=-1分别列明，不算作不同字形。对当前全部229张非reference PNG另做同Unicode样文字形裁白模板检索，三字号均零精确匹配，HP自身正例均10／10通过。样文补查不是完整字库查重，不代表上述缺口已补齐。
