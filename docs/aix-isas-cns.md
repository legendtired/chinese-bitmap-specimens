# IBM AIX / ISAS 繁体宋体 · 24点字面

只收录本款同源繁体扩展，按有效汉字字面24点筛选。中文原存储26×27和配套Roman 13×27完整保留，不把27px行格说成新字号，不裁边、补字或缩放。简体版本属于已有ISAS宋24的微调，本次不收；54px版本为2倍放大，也不收。

## 来源与原始度量

[IBM AIX 4.1.5 RS/6000原盘存档](https://archive.org/details/AIX_415_rs6000)，第1盘LCD4-0237-00.1_2，X11.fnt文件集中的cns1ucs.pcf、cns2ucs.pcf和Roman27ucs.pcf。只读解析BFF容器及压缩数据，不执行安装器或历史程序。[源元数据](../data/aix-isas-cns-sources.json)记录容器位置、SHA256和字体属性，不含字模。

- 中文标记IBM_AIX Cjk_song Medium，UCS2.CNS11643.1986平面1／2。原PCF编码表已是Unicode，不能再次把码位当CNS坐标转换。
- 中文字框26×27、advance 26；Roman字框13×27、advance 13；共同ascent 26、descent 1、left bearing 0。
- 两平面全部13,061个非空汉字逐字检查，最大墨迹均24×24。因此按24点字面筛选，存储字段仍为26×27；PCF原PIXEL_SIZE为27、POINT_SIZE为170、分辨率100dpi，分别保留，不互相改写。
- 固定两行“視野無限廣，窗外有藍天。”及“0123456789 AaBb GgMm !?:+-.”，四周4px、行间4px，PNG为359×66。空格保留原字进，无额外字间距。

## 覆盖与编码冲突

CNS1含5,411、CNS2含7,650个非空U+3400–9FFF汉字，合计13,061，两平面汉字无交集。对Python Big5的13,061汉字，按相同Unicode覆盖13,060；原库有“彞”U+5F5E而不是“彝”U+5F5D。本次不互换、不借字，不能称完整Big5。这是现代Unicode覆盖对照，不是历史CNS到Big5转换表的证明。

Roman有95个可打印ASCII，空格原本为空白。CNS1的U+005B／U+005D是全宽方括号，与Roman半宽“[]”同码异图。固定样句没有方括号，重绘脚本明确从Roman选ASCII，不依靠字典覆盖顺序。若未来另做完整Unicode导出，须明确Roman ASCII优先、保留CNS原槽并披露差异；本次没有完整字体导出。

CNS2声明默认码U+3000，但其自身编码表没有此码，不补造默认字形，不把fallback计覆盖。

## 独立核验

[独立审计](../data/aix-isas-cns-independent-audit.json)用原始结构与逐位解码，对照Pillow的全部13,642个字形、9,532,107个像素、度量、编码及属性，全部一致。两个CNS文件末尾BDF_ACCELERATORS目录声明100字节，实际剩余72字节，是带ink bounds的accelerator；字形表完整，保留此原容器差异，未丢弃像素。

原生位图存储已核验，不据此推断逐字手绘过程。1993 ISAS、1992 IBM是内部版权年份，不是已证实的首次设计日期。

## 去重结论与限制

[聚合报告](../data/aix-isas-cns-dedup.json)仅公开计数与结论：历史BDF比较范围为221份，另做DEC映射及HP24补查；234条基线中检查了233张非reference样图。公开报告只列下述五个已公开参照的重合数字，不附完整参考清单、逐样图记录或命中坐标。

- 与已有ISAS宋24共享4,382汉字，其中1,427裁白同形，32.57%；另8,679字不在该简体参考字集中。明确是同源繁体扩展，不称全新独立设计。
- ETen Taipei24、HP-UX Sung24、DEC Sung24在各自共有汉字中分别仅1字裁白相同；DEC Sung32为零。尺寸不同的整框比较和裁白比较分开记录。
- 旧BDF包缺49个当时当前ID；HP24另补完整来源比较，其余完整来源及映射缺口仍保留。未映射槽不算不同字形。可得历史撤下源参与比较，不重新收录；未恢复撤下PNG，不声称已补查其样图。
- 233张样图中5张检出零星常用字同形，共7次、涉及3个字，单张最多3字，没有整句匹配。模板搜索只检查同Unicode样文字形是否出现，不能代替逐字完整字体比较，也不能证明原创、无衍生关系或“全库已比完”。

## 离线重绘固定样文

自行取得并确认有权使用上述三份解压PCF，安装Pillow后运行：

```sh
python3 scripts/render_aix_isas_cns.py /本地/三份PCF所在目录 /本地/尚不存在的输出目录
```

脚本先校验所有输入的精确SHA256，仅输出一张固定PNG；不联网、不安装字体，不内嵌字模，不导出完整BDF或字模数组。错误输入或已有输出目录会拒绝，不以其他字体填缺字。精确源回归：

```sh
AIX_CNS_PCF_DIR=/本地/三份PCF所在目录 python3 tests/aix-isas-cns.test.py
```
