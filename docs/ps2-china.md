# 中国版 PlayStation 2 的 24×24 点阵

本条展示 SCPH-50009 中国版 PS2 的 ROM2 内 `GB18030` 字模，以及**同一 ROM2** 的 `FNTHANCH` 英数。两者都是预先存储的单色位图，本次不经过矢量取模、平滑、缩放、补字或字体替换。

目前证据确认的是原生位图存储。尚无原厂设计资料证明每个字都是手工逐点绘制，不能把 ROM 点阵等同于已证实的手绘历史。

## 来源与校验

[完整转储资料页](https://archive.org/details/scph-50009-cn-190-030623-fixed-underdumped-rom-2.7z)标注为修复 ROM2 欠量的 SCPH-50009 存档。资料由第三方保存，不是本次从实机读取，也不是再分发授权证明。

本地使用时先自行取得并确认有权处理对应资料，离线解包出 `SCPH-50009 CN 190-230603.ROM2`。脚本按内容校验，不依赖文件名。只支持下面的完整 ROM2，不接受网上另见的 512KiB 欠量版本。

| 对象 | 大小 | SHA-256 |
| --- | ---: | --- |
| 完整 ROM2 | 2,097,152 字节 | `fe61257af2cd2675256c2dcc5ffd78eae1a22d24f816571c2f927a93ed3bcc2d` |
| `FNTHANCH` | 6,912 字节 | `26e3532a0609f8051aa9b3755a20ed07cc4ce5aa94560392896175e0d9895281` |
| `GB18030` | 2,058,552 字节 | `d9e535e7497b8e444e642715e420ccb0d7118bec05ec71f36e585670db4fd5a4` |

原始压缩包大小 6,459,620 字节，SHA-256 为 `e80126efb70834a5c895b589af1c1b9c9369d064443ee4bcd424d8b704cbd597`，SHA-1 为 `6d935bc5817b44e40c49c756adfa21b47917a64e`。仓库不附带压缩包、ROM 或完整字模。

ROMDIR 逐项解析得到 `FNTHANCH` 在 `0xD0`、`GB18030` 在 `0x1BD0`。模块地址、长度及 SHA 均复核。[另一个历史存档的 512KiB 前缀](https://github.com/Abdess/retrobios/blob/main/bios/Sony/PlayStation%202/SCPH-50009_BIOS_V10_CHN_190.ROM2)与完整 ROM2 开头逐字节相同，但它本身不足以导出全库。ROM2 的 EXTINFO 有 `20030224-102654` 生成字段，不能据此推定字体最初设计年份。

## 字框与英数字来源

每字 72 字节，按 24 行、每行 3 字节排列，高位像素在左。完整中文模块有 28,591 个槽，其中 28,426 个非空。槽位数量不等于已确认的 Unicode 字符数量。

`FNTHANCH` 有 96 个相同大小的记录，对应自然顺序 `0x20–0x7F`。本站只声明 U+0020–U+007E 的 **95 个可打印 ASCII**，包括原始空格；DEL 不计作可打印字符。样图英数逐字来自这个模块，未借用 PSP、电脑系统或其他字库。

ASCII 的墨迹只占存储框左半边，最大宽度 12 像素；原始记录仍是 24×24。尚未核实 PS2 运行时字进和基线，所以样图保留完整存储框，不能把显示留白解读为实机排版。

标准图是两行：中文固定样句、同 ROM 的 ASCII。每字完整 24×24，字间额外 1px、行间 4px，是样图排版间隔，不是字体自带度量。图像为 674×52，未统一缩小英数或裁去原字框。

## 已核映射与未核范围

已核的四段物理槽位：

| 编码区域 | 首槽 | 索引方式 |
| --- | ---: | --- |
| A1–A9 / A1–FE | 0 | 每行 94 槽 |
| B0–F7 / A1–FE | 846 | 每行 94 槽，跳过未存储的 AA–AF 全角行 |
| 81–A0 / 40–FE，排除 7F | 7,614 | 每行 190 槽 |
| AA–FE / 40–A0，排除 7F | 13,694 | 每行 96 槽 |

默认以 Python `gbk` 的双字节映射解释以上区域，得到 **21,638 个已映射字符**，包含 U+4E00–U+9FA5 全部 **20,902 个汉字**，并包含全部 **6,763 个 GB2312 汉字**。再加入同 ROM 的 95 个 ASCII，本地 BDF 共 21,733 个 Unicode 字符。

这**不是完整 GBK 或 GB18030 导出**：GBK 另外 153 个符号映射位于未核的 A8/A9 低尾字节区域；四段内还有无法按 GBK 解码的槽位，一些有墨迹，但不猜 Unicode。其余 GB18030 符号、扩展 A、四字节编码及补充平面范围也未在此导出器中确认。未映射不等于原库缺字。

可选 `--repertoire gb2312` 单独按 GB2312 解释，得到全部 7,445 个赋码双字节字符，含 6,763 个汉字；加 95 个 ASCII 为 7,540 字。GB2312 与 GBK 在 A1A4（U+30FB／U+00B7）、A1AA（U+2015／U+2014）存在 Unicode 解释差异，因此两模式分开，不静默混合或增加别名。

## 离线重绘与本地导出

Python 3.9+，只用标准库。脚本无联网步骤、不执行固件、不内嵌字模，先核完整 ROM 和两个模块 SHA，再读取数据。

```sh
python3 scripts/ps2_china_bitmap_export.py "/本地路径/SCPH-50009 CN 190-230603.ROM2" --output local-research/generated/ps2-china
```

输出固定中文、诊断「片版牌局」、繁体、同 ROM ASCII 的原尺寸 PNG、网站两行 PNG 和校验报告。默认不输出完整字体。

需要在本地研究已核映射时：

```sh
python3 scripts/ps2_china_bitmap_export.py "/本地路径/SCPH-50009 CN 190-230603.ROM2" --output local-research/generated/ps2-china-bdf --export-bdf
python3 scripts/ps2_china_bitmap_export.py "/本地路径/SCPH-50009 CN 190-230603.ROM2" --repertoire gb2312 --output local-research/generated/ps2-china-gb2312 --export-bdf
```

BDF 把完整存储框展开为 `BBX 24 24 0 0`、`DWIDTH 24`、ascent=24、descent=0。**这些是明确的导出约定，不是已知 PS2 原机 advance 或基线**；也不把 12 像素墨迹宽度伪造为实机字进。输出存在时整批拒绝覆盖，不接受符号链接输入或输出目录。

公开测试：

```sh
python3 tests/ps2-china.test.py
```

另有可选私有源测试和独立逐位解码核对；未提供 ROM 时公开测试会明确跳过私有源项目，而非声称源文件核验已通过。

```sh
PS2_ROM2="/本地路径/ROM2" python3 tests/ps2-china.test.py
python3 scripts/verify_ps2_bitmap_decode.py "/本地路径/ROM2" --report local-research/ps2-independent-audit.json
```

独立验证器不调用原解码器来产生参考像素，改以逐字节、逐位寻址核对全部28,591个中文物理槽及96个FNTHANCH记录，共16,523,712个像素；另独立枚举编码范围，核对BDF回读、SWIDTH=960与PNG像素/间隔。报告只含计数、SHA和状态，不写完整字模。

## 查重边界

对 `c2405dd` 时的 224 项原始 PNG，224 个 SHA 均核对；其中 223 项有共同汉字样句，均可排除样图完全相同，ChinaSea 资料图没有可比样句。新增 Windows 3.2 13／20 点另核，不能把旧 224 项结果直接称作当前 226 项全量字库查重。

同 Unicode、仅裁空白边、不缩放的全量比较：HZK24S 和 AIX clib24s 各有 186/6,763 汉字相同；HZK24H/K/F 与 AIX clib24h/k/f 各为 0/6,763。已撤下的 /efont24 为 427/6,763 相同，排除整体换名。相同个别简单字形不代表同一字库。

后续对恢复的221份BDF容器逐份校验SHA并按编码元数据比较，其中211份有可映射的共有汉字；部分容器仅保存有限字集，不能把它称为221套完整原库。另用13份原始Taipei PCF、原始Big5 BDF和cch24的HBF字模交叉核验，补齐此前缺失的历史来源。Taipei b/r/s24及六款20点体各为0/13,061，Dotum24与Batang24各为0/4,620；cch24整框0/6,763、裁白边1/6,763。恢复的目录ISAS宋体24和ccic_chkan_24则为整框931/6,763、裁白边939/6,763（13.88%），已用GNU原始gb24st.bdf及第二解析器复核。这与AIX clib24s的186/6,763是不同来源的结果。本轮未发现接近整库相同的重复，但保留这项部分重合证据；低精确重复不能证明原创、独立设计或手绘历史。[聚合审计](../data/ps2-history-dedup.json)仅包含来源SHA、计数和方法，不包含字模。

当前 curation 有 34 个 removedIds。历史记录中可恢复的 9 张 PNG 均校验 SHA，其中 8 张有共同样文，均不同；GB48 资料图无共同字样。旧 Solaris 12／14／20 和新增 Windows13／20 另作全量源像素比较：各有6,763个共有汉字，均为0个墨迹完全相同。另有部分更早移除项的历史样图不可恢复；上述原始字模补查已覆盖Taipei b/r/s24、20点族、Dotum24、Batang24和cch24等具体缺口，仍不能宣称穷尽所有历史字库或所有被移除设计。未恢复任何撤回条目，也不把非重复视为手绘历史证明。
