ADP for Windows 3.1.05（2003）配套CFONT.24，直接读取24×24预存1-bit字模；原程序Big5寻址、72字节读取和Windows单色CreateBitmap路径已静态核验。1995-08-30仅为保存的字体文件时间，不是认证设计年份；不称设备ROM或已证手绘设计。

## 覆盖和边界

严格Big5基本汉字13,061/13,061；兼容汉字2另计。十、卅各有两种不同原字模；严格Big5汉字13,063个唯一Unicode、13,065个原变体。另7个CP950扩展汉字分列，不混入基本Big5覆盖。本预览及重绘入口使用的CFONT.24不含半角ASCII，未外补；相关Windows源MINGLI24.FON另有12×24半宽ASCII的128个原槽，本次不显示、不借入样图。

仅处理自行取得且有权处理的本地 CFONT.24，大小 976680 字节，SHA-256 `1f46c0240a1a840f944baed0627c734351672c0dd388528313c9421d6a957121`。源文件不随仓库附带，不执行原软件。

```sh
python3 scripts/hitech_adp3_24_specimen.py --source /path/to/source --output /existing/directory/new-preview.png
python3 scripts/hitech_adp3_24_specimen.py --source /path/to/source --output /existing/directory/new-preview-4x.png --scale 4
```

需要 Python 3.9+、Pillow、POSIX 的 no-follow 文件操作支持。只支持固定样文「視野無限廣，窗外有藍天。」及1×/4×；拒绝不同源、任意文字、符号链接和覆盖已有文件。不同PNG编码结果必须重新审阅，不能静默替换批准图片。

## 查重

除上述已合并的MINGLI24共同原码全同关系外，其他参考的查重边界如下。

原250条记录不等于250个独立字族，也不等于最新目录全覆盖。全部共同非空同码汉字保留原变体，比较只裁外围空白并取横纵各±1px的最大完整墨迹Dice，不缩放、不改变内部空白。最高大交集为CMEX明24：13,061共同Unicode中3字精确，平均Dice 0.659583。

对当前247目录原有45项缺口，补查分为：9项完整已核汉字范围、1项可恢复源子集、12项有限样字、1项CCDOS条件映射及原槽池、6项原槽或受限来源池、3项此前已恢复参考；仍12项源或布局未闭合，ChinaSea仅参考图。9项“完整”只指已核汉字范围，不能扩大成所有非汉符号也已认证。

补充22层同码比较加4层已排除源，对双候选合计52次，并非52个新增完整字库。另对19个原形状池及CCDOS做精确与≥0.90 Dice控制，保留条件编码、未定码和来源子集限制；HITECH每个有高相似命中的池最多仅1个Unicode，没有整层高重复。原池形状命中不用于反向赋Unicode，也不证明更低阈值或缩放后的关系。

固定预览专项审计247项，但只有18个有限样字警报层能定位逐字：13项有原renderer依据，5项仅元数据约束，后者证据较弱。HITECH共同样字无精确命中，最高HP-UX Sung24仅10字、平均Dice 0.645785，不能外推整库。另12项未闭合字位和ChinaSea参考图不作阴性证明。
