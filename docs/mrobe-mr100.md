# Olympus m:robe MR-100 12×12

本条展示 MR-100 **2.17V（2005年发布包）**中的原生1-bit点阵。汉字存储框为 **12×12**；15,646个汉字墨迹为11×11，但“桅、淖、费”用足12行，不能将整库裁成11×11。配套英文来自同一个 `MR100.fnt`，保留原存不等宽字框。本条不推荐，原242项与17项推荐保持不变。

## 来源与年代

- [Daniel Stenberg 保存的 MR-100 目录（固定提交）](https://github.com/bagder/sansa/tree/4f488ff82ade4df773a3d802965575c1cb8d9a18/mrobe100)：`bagder/sansa` 从研究者原网站导入的升级器解包保存件。本次不是直接取得 Olympus 原始 EXE；也不是 Rockbox 替代字体。
- 保存包内 `Firmup.ini` 与 `SYSTEM/VERSION.INI` 都注明 `FirmVersion=2.17V`。`SYSTEM/PP5020.mi4` 的 MD5 为 `7417ee459d86e22d795240899441ef07`，与[同一研究集合的历史原固件校验表](https://github.com/bagder/sansa/blob/4f488ff82ade4df773a3d802965575c1cb8d9a18/mi4.t)相符。
- [Olympus 2005-05-30 官方公告](https://support.jp.omsystem.com/jp/support/cs/npls/info/nplsif20050501.html)独立确认2.17V发布。版本先由包内双INI确认，不靠公告给未知文件赋版本。
- 保存包为4,590,203字节，SHA256 `4f874b6c5f13036fdf0d2e03b5f50e2444d72492b2e0b9f355af234db5699bc7`；目标 `MR100.fnt` 为1,781,424字节，SHA256 `e81b038173cabc11680e8e3f11a528c5b668420853014a94e8b9ce95de248a4e`。
- 字体的容器时间戳为2004-11-15，仅是保存元数据，不作为设计日期。尚无厂方字体专属哈希、签名或原EXE逐字节复核。
- MR-100英文快速手册说明产品屏幕字体属于 Ricoh。这不证明全部字模的设计作者、全部手工制作，或与另一 Ricoh 字库相同。第三方保存也不等于开放授权。

## 原生结构与覆盖

原头部定位字符记录和映射区；20,278条有序的“uint32 Unicode + uint32 glyph index”对覆盖全部索引。每字52字节记录给出原宽、高、逐行字节数与像素地址，另一个独立偏移数组逐项一致。位图逐行、高位在左，完整行的未用低位均为零。不执行固件，不栅格化轮廓。

- 20,277个槽的像素完整，其中20,274个非空。非空 U+3400–U+9FFF 汉字16,400个，另有36个兼容汉字。
- GB2312全部7,445个标准码位均有映射，6,763个汉字非空齐全。
- Big5基本汉字13,061/13,061及两兼容汉字齐全。其他符号U+02CD、U+2574缺映射，不能称完整Big5字符集。
- 同层95个可打印ASCII均有映射，空格为空，94个可见字非空；原存宽2–12px、高12px，不改成统一半宽。
- 全部16,400个汉字原存12×12，最大墨迹宽11、高12。墨迹通常11×11，不代表存储框或全部字形仅11高。

**唯一不完整槽：U+3164。** 原记录要求24字节，偏移1,781,404之后只剩20个零字节。该槽排除，不补零、不计完整像素验证；不影响汉字、ASCII或固定样文。不能称20,278槽全部通过。

全部20,277个完整槽、2,898,744个存储像素经另一条偏移表和Pillow原始1-bit解码独立核对，逐字节回包一致。完整位图区间不重叠；包内字体与研究输入一致。此机械验证不是逐字人工校对或实机运行验证。

## 固定样图与排版

固定PNG为171×44，包含简体、繁体及同层英数三行。汉字两行各144px，英文行171px。保留原像素与原存宽，逐字连续放置，行距16px是诊断排版；不裁框、不补画、不换字、不平滑。

原记录还含重复宽高、0和-2等字段，运行时advance、bearing和基线语义未由设备或原程序独立确认。固定样图不是原机完整UI排版复刻。

## 查重范围

历史202、当前补充13、冻结近期26层及PSP直接对照，均完成可用同Unicode非空汉字交集的精确及近似比较。统一比较域为U+3400–U+9FFF，不将36个域外兼容汉字算进16,400分母。精确仅裁外围空白；Dice允许横纵各±1px平移，保留全部墨迹，不设尺寸差门槛、不裁切、不缩放。

- Dotum原生12：共同7,083字，434字精确同形，平均Dice 0.823940；2,238字≥0.90，1,232字≥0.95。局部高相似仍需说明。
- Galmuri11：221/6,461精确同形，平均Dice 0.813130。
- 在覆盖全部16,400候选汉字的对照中，Zpix12最高：330字精确，平均Dice 0.779164。
- 近期26层最高为P802小号：42/9,443精确，平均Dice 0.734817；PSP为0/16,400，平均Dice 0.380986。
- 方正12仅15字固定样本：0/15精确，平均Dice 0.730768，不能外推整库。
- 所有已查来源的同码精确命中并集为1,190/16,400（7.2561%）。其余字只表示未在已查来源找到精确同形，不是独创证明。

这些层有重叠，不是241套独立字体。冻结目录原覆盖196/241个ID，仍有45个缺口；另直接比较PSP后，相当于收录前197/242个ID，原45缺口未消除。部分来源仅小样本；不称全站、全库去重，也不据此推定作者或无同源关系。

## 离线重绘固定样图

自行取得有权处理且SHA匹配的本地 `MR100.fnt`。公开工具仅读取固定三行所需原映射与像素，不含字模，不联网、不执行固件、不导出任意文字、完整字体或字库子集。

```sh
python3 scripts/mrobe_mr100_specimen.py \
  --source local-research/mrobe/MR100.fnt \
  --output local-research/generated/mrobe-fixed.png
```

设置原输入可运行源到PNG回归；测试还通过另一套偏移数组及独立Pillow路径逐像素重建固定样图：

```sh
MROBE_MR100_SOURCE=local-research/mrobe/MR100.fnt \
python3 tests/mrobe-mr100.test.py
```

没有私有输入时明确报告未运行源回归，仅检查公开PNG、元数据、原242项保真和错误SHA拒绝。不把PNG哈希检查冒充源像素验证。
