# H-01B / H-01 JCE · 16×16

![H-01B / H-01 JCE 原生点阵固定样图](../assets/specimens/h01_16.png)

**来源。** [MAME 的 H-01 系列驱动](https://github.com/mamedev/mame/blob/master/src/mame/misc/h01x.cpp)记录了机型、硬件和 ROM 校验。通过两版各自的原机固件在本地仿真中恢复字模：汉字为 16×16、半角英数为 8×16，均保留原位图的 16 行。比较已核范围，两版的 3,755 个一级汉字及 95 个 ASCII 槽逐像素相同，所以合为一项；不据此推断所有固件内容相同或认定设计者。

**使用场景。** [1992 年《无线电》第 8 期第 14 页](https://software-archive.tifan.la/radio-magazine/1992/003460.html)介绍了把整屏字幕字卡录入家用 VHS 的流程。这是当时的使用资料，不是对具体录像的鉴定，也不等于电视台播出时的画面叠字。

**覆盖。** 已核 GB2312 一级全部 3,755 个汉字，均有墨迹；不声称完整 GB2312。确认 93 个常用 ASCII 映射，含空格，92 个有墨迹；反引号、波浪号不纳入。原机的半角逗号与句号可识别，但标准样文的全角逗号、句号未确认相应原机映射，各留一整格，不用半角字或其他字体补画。样图仅用这些已确认的原像素重排，不是机器画面截图。

公开技术资料不代表授权转发原 ROM 或完整字体。这里只附固定样图、来源与核验边界。
