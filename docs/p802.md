# Sony Ericsson P802 小号12点字面

只收录P802 R2A07的UID 0x4823小号原生点阵。典型汉字墨迹11×12、汉字字进12px，保留14px原生行格、ascent 11和每字bearing。12点字面不是12高存储框，网站按14高行格筛选；层最大宽度15px。中号／大号不新增。

## 覆盖与固定样文

- 10,406个Unicode映射码位，9,587个非空CJK汉字（U+3400–U+9FFF范围）。
- 全部6,763个GB2312汉字非空；严格Big5编解码器映射的13,061个汉字中有6,998个。繁体覆盖不完整，不外推为完整Big5、GBK或Unicode。
- 同层95个可打印ASCII均有记录，只有空格无墨迹并保留原字进。
- 固定第一行用实际简／繁Unicode句子，第二行用同层ASCII，全部有字。不借字、不缩放、不补画。画布300×40，外边4px、行间4px为展示布局，未声称实机UI复刻。

## 来源与可复核链

[Twister历史手机固件资料页](https://archive.org/details/Twister_Mobile_Phone_Flashing_Box)内Firmware.zip的P802目录，PD1／PD2包名分别为p802_r2a07_cxc16209_pd1.zip与p802_r2a07_cxc16209_pd2.zip。配套PD1的原始ASCII字符串CXC16209 R2A07 030416 21:13对应2003-04-16 21:13，不作为字形设计日期。

实际字体来自PD2的ROFS（ROLF签名）目录Linnea.gdr：目录文件名偏移0xde2、载荷地址0x480f38、物理文件偏移0x480f3c（前4字节地址前缀），长度1,277,578字节。GDR为版本40、15层，本次只接受UID 0x4823。

[data/p802-sources.json](../data/p802-sources.json)记录ZIP、PD2和GDR的SHA256。GDR SHA256：b830cc56393523e399fcdc349f865d57fe02b4ead0fc64139eb76e035e538961。外层存档成员CRC及内部ZIP CRC已核；提取不运行刷机程序、安装程序或固件。

Unicode区段、内联8字节字符指标和LSB先行单色RLE直接解码，保留ascent、墨迹高、左右bearing、advance和每个原像素。新脚本与独立原解析的全部10,406码位指标／行像素逐项一致，固定PNG由独立布局逐像素核对。详见[覆盖](../data/p802-coverage.json)和[独立解析审计](../data/p802-decode-audit.json)。Linnea只是资源文件名，不证明设计师、设计来源或逐点手绘历史。

## 去重范围

[data/p802-dedup.json](../data/p802-dedup.json)区分具名完整字符层、恢复的历史索引及固定样字检查。精确比较只裁外缘全空白，不缩放、不替换码位，分母为实际共同非空字符。

- 具名完整GB汉字基线最高为SimSun18030 v2.06内嵌12点：507/6763（7.497%）。Nokia QD12为331/6763，SimSun 5.03小号101/6763，Palm CJKOS FGB12为72/6763。
- 新恢复Sun GBK12：52/6763（0.769%）；全部9,587个共同汉字中61个精确同形。允许±2px整数平移、不缩放或裁剪的近似检查中，GB汉字像素对称差中位数27，Dice中位数0.752，Dice≥0.95仅265/6763（3.918%）。这些指标不支持大范围轻微修改近重复，也不证明原创。Sun GBK14／16／20／24共同GB汉字精确同形均为0。
- Casio12为47/6763；Casio24、PS2 24点、Samsung R208 16点共同GB汉字均为0。
- 历史索引202条记录均完成共同汉字与GB汉字两种范围比较：193条常规完整可用来源、9条来源或轮廓导出受限记录，不能称202套独立原生字体。它覆盖当前目录的162条常规记录及9条受限记录，其余68条不在此索引中，部分另有具名专项补查。
- 发布基底535b92f的239条中，238张原生固定PNG全部检查，1张参考图不作字库比较，未发现同码样字精确图案命中；已撤来源的23份可用样字也无命中。这只是样文检查，不是整库查重。

未声称穷尽所有当前、历史或已撤字体，未收录未批准候选，也不把小号的结论移用于同文件其他层。

## 严格离线重绘

自行取得并确认有权处理匹配SHA的本地输入，安装Pillow后运行：

```sh
python scripts/p802_specimen.py local-research/Linnea.gdr --output local-research/generated/p802
python scripts/p802_specimen.py local-research/p802_r2a07_cxc16209.pd2 --container pd2 --output local-research/generated/p802-pd2
python scripts/p802_specimen.py local-research/p802_r2a07_cxc16209_pd2.zip --container zip --output local-research/generated/p802-zip
```

输出目录必须不存在。脚本先核整个输入SHA、长度、ZIP CRC与ROFS目录，再核GDR结构／码位数／覆盖，最后只生成固定两行PNG及聚合coverage.json。它复用现有手机解码器的已核结构，不改P908／9210C配置，不联网、不输出完整GDR、BDF、pickle或任意字库子集。可设置P802_GDR、P802_PD2、P802_ZIP后运行`python tests/p802.test.py`核对精确输入链和固定PNG。
